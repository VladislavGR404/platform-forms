# Конструктор форм отклика для карьерной платформы

Сервис позволяет менеджерам самостоятельно конструировать формы отклика для стажировок и мероприятий, публиковать их по уникальной ссылке, а студентам — заполнять эти формы. Также встроена аналитика для отслеживания конверсии и причин, по которым пользователи бросают заполнение.

## Технологический стек
- **Backend:** Node.js (Express), SQLite3 (локальная БД, автономность).
- **Frontend:** HTML5, Vanilla JS, Bootstrap 5.
- **Безопасность:** Защита от SQL-инъекций (Prepared Statements), защита от XSS (экранирование на фронтенде), серверная валидация данных.

## Запуск проекта

Для запуска требуется **Node.js версии 20 или новее**.

1. Установите зависимости и старт:
```bash
npm install

npm start
```


## Дополнительно 
#### Тестовые данные
**Что делает `seed.js`:**

- Полностью пересоздает файл базы данных.
    
- Создает 2 готовые формы («Frontend Developer» и «UI/UX Дизайн»).
    
- Добавляет 9 тестовых ответов от студентов (с именами, почтой, файлами).
    
- Генерирует фейковую статистику отвалов для проверки «Воронки конверсии».
    

1. **Как запустить:**  
Откройте второй терминал (не закрывая сервер) и выполните:

bash
```bash
 node seed.js
```
